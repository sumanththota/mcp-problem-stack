02 The Holdback Mechanic

HOLDBACK_WINDOW = max(L) − 1 = 59

Three tracked PII patterns, each with a Max Pattern Length (L). The buffer never releases the last L−1 characters of the largest one — 59 — because that's the most a still-arriving match could need to complete.

patternregex (src/llm_gateway/patterns.py)L
ssn\b\d{3}-\d{2}-\d{4}\b11
credit_card\b\d{4}[ -]?\d{4}[ -]?\d{4}[ -]?\d{4}\b19
email\b[\w.+-]+@[\w-]+\.[\w.-]+\b60 (deliberate ceiling)

tests/test_buffer.py — short text, never crosses 59

Three appends, each returns "" — the whole exchange stays under the window, so nothing is safe to release until stream end.

append("Sure, my email is sumant") → ""
append("h@gmail") → ""
append(".com") → ""
flush() → "Sure, my email is [REDACTED]"

The match only completes on the third append — held back exactly long enough.

test_credit_card_never_leaks_mid_number — long text, flushes mid-stream

Long enough leading text to push past the 59-char window while the card is still arriving. Split right after an internal space — the exact spot the rejected whitespace-rule (ADR-0001) would have leaked "4111 " early.

"Here i"→ "s your card inf"→ "ormation which you reque"
"sted earlier today: [REDACTED]. Thanks for banking with us!"

Deltas in: "...requested earlier today: ", "4111 1111 1111 ", "1111", ". Thanks...". No fragment before the last one contains a single digit.

03 Overlap Resolution

ADR-0002 — the bug that was actually found and fixed

Applying each pattern in PATTERNS list order, one at a time, let whichever pattern ran last silently win an overlap. Fix: collect every match first, then resolve.

before — order-dependent 
text = "contact 4111111111111111@example.com for details"

# credit_card runs before email in PATTERNS —
# it matches + replaces the 16-digit run FIRST:
text = credit_card.sub("[REDACTED]", text)
#   -> "contact [REDACTED]@example.com for details"
# email regex now has no digit run left to match on:
text = email.sub("[REDACTED]", text)
#   -> unchanged: "@example.com" leaks in the clear
contact [REDACTED]@example.com for details

credit_card "won" simply by running first — an accident of list order, not a rule.

after — longest-span-wins 
spans = []
for pattern in PATTERNS:               # scan ORIGINAL text,
    for m in pattern.regex.finditer(text):   # every pattern,
        spans.append((m.start(), m.end(), pattern.name))

spans.sort(key=lambda s: (s[0], -(s[1]-s[0])))
# email span [8,37) contains credit_card span [8,25) —
# same start, email is longer -> sorts first, kept;
# credit_card overlaps kept span -> dropped.
contact [REDACTED] for details

Matches tests/test_patterns.py::test_overlapping_matches_resolve_to_the_longest and is proven order-independent by reversing PATTERNS in the same file.

04 Module Map

What's actually on disk

llm-redaction-gateway/ — a FastAPI gateway package plus a hand-built mock upstream, used the same way Task 2's MCP security gateway used a mock downstream (SPEC.md).

src/llm_gateway/app.py
Single streaming route. Owns the FastAPI app, the httpx.AsyncClient lifespan, and event_stream() — the loop that ties buffer + patterns to the wire.
src/llm_gateway/buffer.py
HoldbackBuffer. One instance per request, never shared. append() / flush() / read-only held_length. hot path
src/llm_gateway/patterns.py
PIIPattern dataclass, PATTERNS list, redact(). Owns HOLDBACK_WINDOW (derived from PATTERNS, not hand-set). hot path
src/llm_gateway/upstream.py
stream_chat_completion(). The unmodified wire relay to OpenRouter — logs ttfb_ms/duration_ms/status, no redaction logic at all.
src/llm_gateway/config.py
Reads OPENROUTER_URL / API_KEY / MODEL / LOG_LEVEL from env. No hardcoded model-slug fallback, on purpose.
src/llm_gateway/models.py
ChatMessage / ChatCompletionRequest — mirrors OpenAI's chat-completions request shape.
src/llm_gateway/main.py
Entrypoint. Loads .env, then uvicorn.run("llm_gateway.app:app", ...) on 127.0.0.1:8080.
mock/openrouter_mock.py
Controlled stand-in for OpenRouter (ADR-0003). POST /configure {"deltas":[...]} stores the exact split to replay; POST /v1/chat/completions ignores its own body and streams those deltas back. test double
tests/test_upstream_connectivity.py
Spawns mock (:8195) + gateway (:8180) as real subprocesses, points the gateway's OPENROUTER_URL at the mock, asserts on the actual SSE body. primary seam
tests/test_buffer.py · test_patterns.py
Unit-level: buffer holdback across appends; pattern overlap + order-independence.
scripts/live_smoke_test.py
Manual, opt-in real-OpenRouter round trip — a smoke check, never the correctness seam.
docs/adr/0001–0005 · SPEC.md · CONTEXT.md
